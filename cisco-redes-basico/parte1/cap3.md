**Objetivo:** Comprender los tipos de redes inalámbricas que utilizan los dispositivos móviles y aprender a configurar conexiones Wi-Fi, datos celulares y Bluetooth.

# 3.0 — INTRODUCCIÓN

## 3.0.1 — ¿Por qué estudiar este módulo?

Los dispositivos móviles permiten comunicarnos y utilizar diferentes servicios sin depender de una conexión por cable.

**Ejemplos:**
- Realizar llamadas y enviar mensajes.
- Navegar por Internet.
- Utilizar GPS para obtener indicaciones.
- Conectar auriculares o altavoces.
- Realizar pagos sin contacto.

Un smartphone puede utilizar varias tecnologías inalámbricas simultáneamente, como **4G/5G, GPS, Bluetooth, NFC y Wi-Fi**.

**IDEA CLAVE:** cada tecnología inalámbrica cumple una función diferente.

---

# 3.1 — REDES INALÁMBRICAS

## 3.1.1 — Tipos de redes inalámbricas

### ¿Qué es una red inalámbrica?

Es una red que permite comunicar dispositivos sin utilizar cables físicos entre ellos.

Los dispositivos utilizan señales electromagnéticas para transmitir información.

### Tipos principales

| Tecnología | Función principal | Ejemplo |
|---|---|---|
| 3G/4G/5G | Comunicación mediante redes celulares. | Datos móviles |
| GPS | Determinar la ubicación geográfica. | Google Maps |
| Wi-Fi | Conectar dispositivos a una red local. | Internet doméstico |
| Bluetooth | Conectar dispositivos cercanos. | Auriculares |
| NFC | Intercambiar datos a muy corta distancia. | Pagos sin contacto |

---

## 3.1.2 — Redes celulares

### ¿Qué es una red celular?

Una **red celular** es una infraestructura inalámbrica que permite transmitir información entre teléfonos móviles y estaciones base de un operador de telecomunicaciones.

Los teléfonos utilizan **ondas de radio** para comunicarse con las antenas instaladas en las torres celulares.

### ¿Cómo funciona?

1. El celular transmite señales mediante ondas de radio.
2. La estación base recibe la información.
3. La red del operador transporta los datos o la llamada.
4. La información llega al destinatario mediante las redes correspondientes.

**Ejemplo:** cuando llamas a una persona desde tu celular, la red del operador permite establecer la comunicación.

### Tecnologías celulares

**GSM (Global System for Mobile Communications)**

Es un estándar de comunicación móvil utilizado principalmente en redes celulares de generaciones anteriores.

**3G (tercera generación)**

Permite llamadas, mensajes y acceso a datos móviles.

**4G (cuarta generación)**

Proporciona mayor capacidad de transmisión de datos y permite utilizar servicios como videollamadas y aplicaciones multimedia.

**LTE (Long Term Evolution)**

Es una tecnología de acceso móvil ampliamente utilizada en redes 4G.

**5G (quinta generación)**

Es una generación de redes móviles diseñada para ofrecer velocidades superiores, menor latencia y mayor capacidad de conexión en condiciones adecuadas.

**PARA RECORDAR:**
- GSM = estándar de comunicación celular.
- 3G = tercera generación.
- 4G/LTE = conectividad móvil de alta velocidad.
- 5G = quinta generación de redes celulares.

## 3.1.3 — Otras redes inalámbricas

### 1. GPS — Sistema de Posicionamiento Global

**GPS (Global Positioning System)** es un sistema de navegación que permite determinar la ubicación geográfica mediante señales de satélites.

### ¿Cómo funciona?

1. Los satélites GPS transmiten señales con información de tiempo y posición.
2. El receptor GPS del celular recibe señales de varios satélites.
3. El dispositivo calcula su ubicación utilizando esas señales.
4. Una aplicación puede mostrar la posición del usuario en un mapa.

**Ejemplo:** utilizar Google Maps para conocer tu ubicación.

**IMPORTANTE:** el GPS no necesita conexión a Internet para calcular una posición, aunque las aplicaciones de mapas pueden necesitar Internet para descargar información.

---

### 2. Wi-Fi

**Wi-Fi** es una tecnología de red inalámbrica que permite conectar dispositivos a una red local.

Utiliza ondas de radio para intercambiar información con un **punto de acceso inalámbrico (AP)**.

### ¿Cómo funciona?

1. Un router o punto de acceso emite una señal Wi-Fi.
2. El celular detecta la red disponible.
3. El usuario selecciona la red e introduce la contraseña cuando sea necesaria.
4. El dispositivo establece una conexión inalámbrica.
5. Puede intercambiar datos con la LAN y acceder a Internet si la red dispone de conexión.

**Ejemplo:**

Celular → Wi-Fi → Router → ISP → Internet

### ¿Qué es una zona de cobertura Wi-Fi?

Es un área donde existe una señal Wi-Fi disponible.

Ejemplos:
- Hogares.
- Universidades.
- Bibliotecas.
- Cafeterías.
- Aeropuertos.

**IMPORTANTE:** Wi-Fi no es lo mismo que Internet. Una conexión Wi-Fi puede funcionar dentro de una LAN aunque no exista acceso a Internet.

---

### 3. Bluetooth

**Bluetooth** es una tecnología de comunicación inalámbrica de corto alcance y bajo consumo energético.

Permite conectar dispositivos y accesorios sin cables.

### ¿Cómo funciona?

1. Se activa Bluetooth en los dispositivos.
2. Un dispositivo busca otros dispositivos cercanos.
3. Los dispositivos se identifican y pueden emparejarse.
4. Establecen una conexión para intercambiar información o utilizar servicios compatibles.

**Ejemplos:**
- Celular y auriculares.
- Celular y reloj inteligente.
- Laptop y mouse.
- Celular y altavoz.
- Celular y sistema de audio del automóvil.

### Características

- Comunicación inalámbrica de corto alcance.
- Bajo consumo de energía.
- Puede transmitir voz y datos.
- Permite conectar varios dispositivos compatibles.

**IMPORTANTE:** Bluetooth no requiere Internet para conectar accesorios cercanos.

---

### 4. NFC — Comunicación de Campo Cercano

**NFC (Near Field Communication)** es una tecnología inalámbrica que permite intercambiar información entre dispositivos ubicados a muy corta distancia.

Generalmente funciona a una distancia de pocos centímetros.

### ¿Cómo funciona?

1. Se acercan dos dispositivos compatibles con NFC.
2. Se establece una comunicación mediante campos electromagnéticos.
3. Los dispositivos intercambian información.
4. Una aplicación procesa los datos recibidos.

**Ejemplos:**
- Pagos sin contacto.
- Tarjetas de transporte.
- Tarjetas de acceso.
- Intercambio de información entre dispositivos compatibles.

**IMPORTANTE:** NFC está diseñado para comunicaciones de muy corta distancia.

---

## COMPARACIÓN — GPS, WI-FI, BLUETOOTH, NFC Y 4G/5G

| Tecnología | Función | Ejemplo |
|---|---|---|
| GPS | Determinar ubicación. | Navegación |
| Wi-Fi | Conectar a una LAN inalámbrica. | Red doméstica |
| Bluetooth | Comunicar accesorios cercanos. | Audífonos |
| NFC | Intercambiar datos a pocos centímetros. | Pago sin contacto |
| 4G/5G | Proporcionar conectividad celular. | Internet móvil |

**CLAVES PARA EL EXAMEN:**

- Ubicación mediante satélites → GPS.
- Red inalámbrica doméstica → Wi-Fi.
- Auriculares inalámbricos → Bluetooth.
- Pago sin contacto → NFC.
- Internet mediante una torre celular → 4G/5G.

# 3.2 — CONECTIVIDAD DE DISPOSITIVOS MÓVILES

## 3.2.1 — Dispositivos móviles y Wi-Fi

Los dispositivos móviles permiten comunicarse y acceder a información desde diferentes lugares.

Una conexión Wi-Fi puede ofrecer acceso a servicios de Internet sin consumir los datos del plan celular.

### Ventajas de utilizar Wi-Fi

- Permite acceder a redes locales.
- Puede evitar consumir datos celulares.
- Facilita conexiones en hogares, oficinas y universidades.
- Puede reducir el consumo energético en determinadas condiciones.

### Seguridad en redes Wi-Fi

Cisco recomienda:

1. **No enviar contraseñas ni credenciales en texto sin cifrar.**
2. **Utilizar una VPN cuando corresponda para proteger datos confidenciales.**
3. **Activar la seguridad de la red doméstica.**
4. **Utilizar WPA2 o una protección superior.**

### ¿Qué es WPA2?

**WPA2 (Wi-Fi Protected Access 2)** es un estándar de seguridad utilizado para proteger redes inalámbricas.

Permite implementar mecanismos de autenticación y cifrado.

**WPA3** es una generación más reciente de seguridad inalámbrica.

### ¿Qué es una VPN?

**VPN (Virtual Private Network)** significa Red Privada Virtual.

Permite establecer un túnel de comunicación protegido entre un dispositivo y un punto remoto de la VPN.

**Ejemplo:** conectarte desde una red pública a recursos autorizados de una empresa mediante una VPN.

**IMPORTANTE:** una VPN puede proteger el tráfico a través del túnel, pero no elimina todos los riesgos de utilizar una red pública.

---

## 3.2.2 — Configuración de Wi-Fi

Los dispositivos Android e iOS permiten buscar redes inalámbricas disponibles.

### ¿Cómo conectarse a Wi-Fi?

1. Abrir la configuración del dispositivo.
2. Activar Wi-Fi.
3. Esperar a que aparezcan las redes disponibles.
4. Seleccionar la red deseada.
5. Introducir la contraseña si corresponde.
6. Esperar a que se establezca la conexión.

### ¿Qué ocurre si no hay Wi-Fi?

Si no hay una red Wi-Fi utilizable, el dispositivo puede utilizar datos celulares si:

- Tiene cobertura.
- Cuenta con servicio de datos.
- Los datos móviles están habilitados.

**IMPORTANTE:** muchos dispositivos pueden recordar redes Wi-Fi utilizadas anteriormente y volver a conectarse automáticamente.

---

## 3.2.3 — Configurar la conectividad Wi-Fi manualmente

### ¿Qué es SSID?

**SSID (Service Set Identifier)** es el nombre que identifica una red Wi-Fi.

**Ejemplo:** CASA_WIFI.

### ¿Qué es la frase de contraseña?

Es la contraseña utilizada para autenticarse en una red inalámbrica protegida.

### ¿Cuándo configurar una red manualmente?

Cuando:
- La red no aparece en la lista.
- La difusión del SSID está desactivada.
- El dispositivo no se conecta automáticamente.

### Configuración manual en Android

1. Abrir Ajustes o Configuración.
2. Ingresar a Wi-Fi o Redes.
3. Seleccionar Agregar red.
4. Escribir el SSID.
5. Elegir el tipo de seguridad.
6. Introducir la contraseña.
7. Guardar y conectarse.

### Configuración manual en iOS

1. Abrir Configuración.
2. Seleccionar Wi-Fi.
3. Tocar Otra red.
4. Escribir el SSID.
5. Seleccionar la seguridad.
6. Introducir la contraseña.
7. Pulsar Conectarse.

**IMPORTANTE:**

El SSID, el tipo de seguridad y la contraseña deben coincidir con la configuración de la red.

Las rutas de los menús pueden cambiar según la versión de Android o iOS.

---

## 3.2.4 — Configurar ajustes de datos celulares

### ¿Qué son los datos celulares?

Son un servicio que permite conectarse a Internet mediante la infraestructura de telefonía móvil.

Se utilizan frecuentemente cuando no existe una conexión Wi-Fi disponible.

### ¿Cómo funcionan?

1. El celular detecta una red celular compatible.
2. Se comunica mediante ondas de radio con la estación base.
3. La red del operador proporciona conectividad.
4. El dispositivo puede utilizar los servicios de datos contratados.

### Configuración en Android

Ruta general:

Ajustes → Redes móviles o Conexiones → Datos móviles.

Activar o desactivar según sea necesario.

### Configuración en iOS

Configuración → Datos celulares → Activar o desactivar.

### ¿Qué ocurre cuando cambia la cobertura?

Un dispositivo puede cambiar entre redes móviles compatibles, como diferentes generaciones de redes celulares.

La continuidad de la comunicación depende de la cobertura, la tecnología y el operador.

**IMPORTANTE:** no todos los cambios de cobertura garantizan mantener una conexión sin interrupciones.

---

## 3.2.5 — Bluetooth en una computadora con Windows

Bluetooth también permite conectar accesorios inalámbricos a una computadora portátil.

### Procedimiento general

1. Activar Bluetooth en Windows.
2. Encender el accesorio compatible.
3. Poner el accesorio en modo de emparejamiento.
4. Buscar dispositivos desde la configuración Bluetooth.
5. Seleccionar el dispositivo.
6. Confirmar el emparejamiento.

**Ejemplo:** conectar unos auriculares Bluetooth a una laptop.

**Nota:** el material de Cisco presenta este tema mediante un video. Estos pasos son una explicación general, no una transcripción del video.

---

## 3.2.6 — Conectividad simple con Bluetooth

Bluetooth facilita la conexión de dispositivos sin utilizar cables físicos.

### Aplicaciones comunes

**1. Auriculares manos libres**
- Realizar llamadas.
- Escuchar audio.

**2. Teclado y mouse**
- Controlar dispositivos sin cables.

**3. Sistema de audio**
- Reproducir música desde un celular.

**4. Altavoz de automóvil**
- Realizar llamadas mediante un sistema compatible.

**5. Anclaje de red**
- Compartir una conexión a Internet con otro dispositivo.

**6. Altavoces portátiles**
- Reproducir audio mediante una conexión inalámbrica.

### ¿Qué es el anclaje de red?

El **anclaje de red (tethering)** permite que un dispositivo comparta su conexión a Internet con otro.

Puede utilizar:
- Bluetooth.
- Wi-Fi.
- USB.

**Ejemplo:** compartir los datos móviles de un celular con una laptop.

---

## 3.2.7 — Emparejamiento Bluetooth

### ¿Qué es el emparejamiento?

El **emparejamiento Bluetooth (pairing)** es el proceso mediante el cual dos dispositivos establecen una relación de confianza para poder conectarse y utilizar servicios compatibles.

### ¿Qué es el modo visible?

Es un estado en el que un dispositivo permite que otros dispositivos Bluetooth lo encuentren.

### Información que puede proporcionar

- Nombre del dispositivo.
- Clase o tipo de dispositivo.
- Servicios compatibles.
- Información técnica de Bluetooth.

### ¿Qué es el PIN?

**PIN (Personal Identification Number)** es un código que puede utilizarse para verificar o autorizar el emparejamiento.

No todos los dispositivos modernos solicitan introducir un PIN manualmente.

### ¿Cómo emparejar dispositivos?

1. Activar Bluetooth.
2. Poner el accesorio en modo detectable o de emparejamiento.
3. Buscar dispositivos disponibles.
4. Seleccionar el accesorio.
5. Confirmar el código o PIN cuando corresponda.
6. Esperar a que se complete el emparejamiento.

**Ejemplo:**

Celular → Bluetooth → Auriculares

Después del primer emparejamiento, muchos accesorios pueden reconectarse automáticamente.

**IMPORTANTE:** emparejar no siempre significa que el dispositivo esté conectado en ese momento.

---

## 3.2.8 — Explorar las conexiones del dispositivo móvil

Un smartphone puede utilizar distintas tecnologías inalámbricas simultáneamente.

**Ejemplo:**

- Wi-Fi → navegar por Internet.
- Bluetooth → escuchar música en auriculares.
- Red celular → recibir llamadas y mensajes.
- GPS → determinar la ubicación.
- NFC → realizar un pago compatible.

Cada tecnología cumple una función específica.
